# Install Tabword 0.2.4

1. Open Visual Studio Code.
2. Press `Ctrl + Shift + P` (`Cmd + Shift + P` on macOS).
3. Choose **Extensions: Install from VSIX...**.
4. Select `tabword-0.2.4.vsix`.
5. Reload VS Code if prompted.

No terminal, Node.js, npm, or manual settings changes are needed for end users.
